# Quickpick

A personal Windows productivity tool: a hotkey-summoned popup for capturing notes and screenshots into a chronological digest, copying saved strings, and opening bookmarks.

## Language

**Mode**:
One of the three behaviors the popup can present, in this order — notes, stash, bookmarks. The popup is always in exactly one mode; `Ctrl+Tab` / `Ctrl+Shift+Tab` cycle between them while it's open, and each has its own key and can be clicked in the mode bar.
_Avoid_: Feature, screen, tab

**Summon hotkey**:
The single global hotkey that opens the popup into whichever mode was last active, and closes it again on a second press.
_Avoid_: Trigger key, launch key

**Screenshot hotkey**:
The second global hotkey. Unlike the summon hotkey, it works regardless of whether the popup is open, closing the popup first if one is focused.
_Avoid_: Capture key

**Stash**:
The mode for copying saved strings, in two lists: the **saved** list, a text file of `key~!~value` entries edited by hand in Notepad, and the **scratch** list below it.
_Avoid_: Quick copy (its former name), database (misleading — the saved list is a flat file)

**Stash entry**:
A single entry in either list of the stash; selecting it copies its value to the clipboard.
_Avoid_: Snippet

**Scratch entry**:
A stash entry added from the popup with `Ctrl+Enter`, from whatever was typed or pasted; its value may span several lines. Kept apart from the saved list, newest first, and transient by intent: the oldest drop off, and keepers are moved to the saved list by hand.
_Avoid_: Added entry (its former name), clipboard history (nothing is captured unless added)

**Masked entry**:
A stash entry whose key (or, for a scratch entry, whole text) is prefixed with `*`. Its value is hidden in the list display but copies normally on selection.
_Avoid_: Hidden entry, secret entry

**Command**:
A query starting with `/` and a command name (`/g home`, `/j 123`, `/t 25 write spec`), handed to that command's **launcher** instead of the current mode, in every mode. A `/` line that names no command (`/etc/hosts fixed`) belongs to the mode, so in notes it's a note.
_Avoid_: Prefix, special launcher, colon form (the retired `g:home` / `:g:home` forms); omnibox — considered and rejected as a broader idea; a command is an explicit name, not general intent inference.

**Launcher**:
What a command hands its query to: repo shortcuts (`/g`), Jira (`/j`), the focus timer (`/t`), or a **web search** from the config (e.g. `/p jane` searching a people directory), which opens a configured URL with the typed text in it.

**Command menu**:
The list of commands, each with a short description, shown while a command is being typed (`/`, `/re`) and something in it matches. Choosing one fills it in (`/g `).

**Jira list**:
The `/j` command's list of Jira links: issues and addresses opened from it, newest first, below any **pinned** ones (sprint board, backlog), which always stay on top. Each has a short title, typed after the issue (`/j 123 login fails`) or edited in its file by hand. Text searches aren't kept.
_Avoid_: Jira history, favourites

**Default project**:
The Jira project assumed when a `/j` query is bare digits with no project specified.

**Synthetic entry**:
A list item generated by the app rather than read from a data source — e.g. `/j`'s always-present "open in default project" entry — that occupies position 0 so it's selected by default.
_Avoid_: Placeholder item

**Launcher store**:
The static `key~!~value` file backing the `/g` command (repo shortcuts), separate from the stash, with its own Notepad-edit hotkey.

**Bookmarks**:
The mode presenting the browser's bookmarks, and below them its recent history, as two lists filtered by one shared query, opening selections in a new browser window. Reads Edge's own data.
_Avoid_: Edge launcher (its former name)

**Digest**:
The chronologically-ordered combination of a day's notes and screenshots. A note may span several lines. Quickpick only ever adds to it, in order; it can be corrected by hand, where an entry replaced by `{}` is deleted but keeps its position. Viewed live, a day at a time, as the tail view in notes mode; viewed in full, across all days, in the viewer.
_Avoid_: Log — reserve for the underlying per-day file.

**App shortcut**:
A popup key (default `Ctrl+O` Outlook, `Ctrl+T` Teams; configured under `apps`) that brings a running app's most recently used window to the front, matched by executable name and optionally title. It never starts the app.
_Avoid_: App launcher (it doesn't launch), window switcher (it targets configured apps, not every window)

**Todo**:
A digest entry written as `[] text` in notes mode. It stays open, across days, until a **done** entry pointing at it (by day and position) is logged with `Ctrl+D`; Quickpick never edits it in place.
_Avoid_: Task

**Tag**:
A label such as `#project-x`, switched on or off in notes mode, that's added to every new entry (note, todo, screenshot, timer) while it's on. Tags switch off when the popup closes, so keeping one on means pinning the popup.
_Avoid_: Label, category

**Label**:
A line's opening `word: ` (e.g. `idea: …`, `url: …`), naming who or what that line is about. Any line of a note can carry one, so a note can have several; a todo's comes from its first line. Read from the text rather than stored, and filterable in the viewer, where filtering by any of a note's labels shows the whole note. Typing `:` at the start of a line in notes lists every label used. Unlike a tag, it's per line and never switched on.
_Avoid_: Speaker, prefix

**Continuation**:
A note line starting with `...` (or `…`), which carries the label of the line before it, across notes too; a run of them keeps it until a line with neither a label nor `...`. Screenshots, timers and todos in between don't end the run.

**Pinned**:
The popup state, toggled with `Ctrl+P`, in which it stays open and on top of other windows until `Esc`. Unpinned, it closes as soon as it loses focus, so it's never left open behind other windows.
_Avoid_: Sticky

**Focus timer**:
A single countdown started with the `/t` command (`/t 25 write spec`), logged to the digest when it starts, finishes or is cancelled, and announced with a toast when it runs out.
_Avoid_: Pomodoro, alarm

**Splash**:
The popup's help screen, shown in place of the lists at startup (with an animated title) and on `Ctrl+H`: a one-line summary of today's digest and every hotkey, generated from the config. Any other key leaves it.
_Avoid_: Help page, about screen

**Viewer**:
The separate, manually-launched, web-based application that renders the full digest across all days, with basic formatting and clickable links in notes, and can hand off a screenshot to an external editor for markup.

**Capture context**:
The active window's title at the moment of a screenshot, recorded to aid later recall of what the screenshot was for. It also names the image file, in place of the title GreenShot would give it.
