# Quickpick

A personal Windows productivity tool: a hotkey-summoned popup for quickly copying saved strings, launching Edge bookmarks/history, and capturing notes and screenshots into a chronological digest.

## Language

**Mode**:
One of the three behaviors the popup can present — quick-copy, Edge launcher, or notes. The popup is always in exactly one mode; `Ctrl+Tab` / `Ctrl+Shift+Tab` cycle between them while it's open.
_Avoid_: Feature, screen, tab

**Summon hotkey**:
The single global hotkey that opens the popup into whichever mode was last active, and closes it again on a second press.
_Avoid_: Trigger key, launch key

**Screenshot hotkey**:
The second global hotkey. Unlike the summon hotkey, it works regardless of whether the popup is open, closing the popup first if one is focused.
_Avoid_: Capture key

**Quick-copy store**:
The backing text file of `key~!~value` entries for quick-copy mode, editable directly in Notepad via a hotkey.
_Avoid_: Database (the user's own term, but misleading — it's a flat file)

**Quick-copy entry**:
A single `key~!~value` line in the quick-copy store; selecting it in the list copies its value to the clipboard.
_Avoid_: Snippet

**Masked entry**:
A quick-copy entry whose key is prefixed with `*`. Its value is hidden in the list display but copies normally on selection.
_Avoid_: Hidden entry, secret entry

**Special launcher**:
The rule that treats a prefix and `:` at the start of the query (`g:home`) as selecting a different resolution behavior instead of the current mode's search. In every mode it applies behind a leading `:` (the **colon form**, `:g:home`); the plain form also applies in the search modes (quick copy, Edge launcher) but never in notes, where `g: …` is a labelled note. Unknown plain prefixes fall through to the mode.
_Avoid_: Omnibox — considered and rejected as a broader idea; special launcher is a narrow pre-check on an explicit prefix, not general intent inference.

**Prefix**:
The single character before the `:` in a special-launcher query (e.g. `j`, `g`) that selects which resolution rule applies.

**Prefix menu**:
The list of available prefixes, each with a short description, shown in any mode when the query starts with `:`, no known prefix follows, and something in the menu matches. Choosing one fills in its colon form (`:g:`). A `:` line it can't match (`:x note`, `:) …`) belongs to the mode, so in notes it's a note.

**Default project**:
The Jira project assumed when a `j:` query is bare digits with no project specified.

**Synthetic entry**:
A list item generated by the app rather than read from a data source — e.g. `j:`'s always-present "open in default project" entry — that occupies position 0 so it's selected by default.
_Avoid_: Placeholder item

**Launcher store**:
The static `key~!~value` file backing the `g:` prefix (repo shortcuts), separate from the quick-copy store, with its own Notepad-edit hotkey.

**Edge launcher**:
The mode presenting Edge bookmarks and history as two listboxes filtered by one shared query, launching selections in a new Edge window.

**Digest**:
The chronologically-ordered combination of a day's notes and screenshots. Viewed live, a day at a time, as the tail view in notes mode; viewed in full, across all days, in the viewer.
_Avoid_: Log — reserve for the underlying per-day file.

**App shortcut**:
A popup key (default `Ctrl+O` Outlook, `Ctrl+T` Teams; configured under `apps`) that brings a running app's most recently used window to the front, matched by executable name and optionally title. It never starts the app.
_Avoid_: App launcher (it doesn't launch), window switcher (it targets configured apps, not every window)

**Todo**:
A digest entry written as `[] text` in notes mode. It stays open, across days, until a **done** entry pointing at it (by day and position) is logged with `Ctrl+D`; nothing is ever edited in place.
_Avoid_: Task

**Tag**:
A label such as `#xyz-mtg`, switched on or off in notes mode, that's added to every new entry (note, todo, screenshot, timer) while it's on. Tags switch off when the popup closes, so keeping one on means pinning the popup.
_Avoid_: Label, category

**Label**:
The opening `word: ` of a note or todo (e.g. `bob: …`, `url: …`), naming who or what that one line is about. Read from the text rather than stored, and filterable in the viewer. Unlike a tag, it's per line and never switched on.
_Avoid_: Speaker, prefix (prefixes are the popup's `g:`/`j:`/`t:` launchers)

**Pinned**:
The popup state, toggled with `Ctrl+P`, in which nothing but `Esc` closes it.
_Avoid_: Sticky, always-on-top (it is always on top either way)

**Focus timer**:
A single countdown started with the `t:` prefix (`:t:25 …` in notes), logged to the digest when it starts, finishes or is cancelled, and announced with a toast when it runs out.
_Avoid_: Pomodoro, alarm

**Splash**:
The popup's help screen, shown in place of the lists at startup (with an animated title) and on `Ctrl+H`: a one-line summary of today's digest and every hotkey, generated from the config. Any other key leaves it.
_Avoid_: Help page, about screen

**Viewer**:
The separate, manually-launched, web-based application that renders the full digest across all days and can hand off a screenshot to an external editor for markup.

**Capture context**:
The active window's title at the moment of a screenshot, recorded to aid later recall of what the screenshot was for.
